An interactive study system I built for preparing for my **CSE340 Computer Architecture final examination**.

Instead of studying from scattered lecture slides, notes, practice sheets, and solutions, I organized the important material into one structured interface where I can learn the concepts first and then solve the actual practice problems.

The goal is simple:

> Learn the concept → understand the worked examples → solve the real problems → track progress.

## How It Works

Each chapter is divided into two main sections:

### Learn

The **Learn** section contains:

- Short concept explanations
- Important definitions
- Worked examples
- Key formulas
- Exam-focused notes
- Concepts that commonly appear in written questions
- True/False preparation

The material is written so that I can revise directly from the website without constantly switching between other resources.

### Problems

The **Problems** section contains the actual practice questions selected for final-exam preparation.

For each problem, I can:

- Read the question
- Attempt it independently
- Reveal the solution
- Compare my approach
- Mark the problem as completed
- Mark it for review if I need more practice

## Progress Tracking

The interface includes progress tracking so I can see how much of the revision has actually been completed.

Problems can be treated as:

- Completed
- Needs review
- Not attempted

This makes it easier to identify weak areas before the exam instead of repeatedly studying topics I already understand.

## Study Philosophy

The project is intentionally exam-focused.

It does not try to replace a full Computer Architecture textbook.

Instead, it concentrates on the concepts, explanations, calculations, and problems most relevant to my CSE340 final preparation.

The emphasis is on:

- Understanding before memorizing
- Solving problems independently
- Identifying weak concepts
- Revising efficiently
- Practicing the exact style of questions expected in the exam
