An interactive study system I built for preparing for my **CSE340 Computer Architecture final examination**.

https://siffyyrox-x.github.io/Computer-Architecture/

## Topics Covered

The current version focuses on Chapters 2–5 of Computer Architecture.

### Chapter 2 — Instructions: Language of the Computer

- Instruction Set Architecture
- Machine instructions
- Registers
- Arithmetic operations
- Memory operands
- Logical operations
- Conditional operations
- Procedures
- Addressing
- Instruction encoding
- Related concepts and True/False preparation

### Chapter 3 — Arithmetic for Computers

- Integer arithmetic
- Addition and subtraction
- Signed and unsigned numbers
- Multiplication
- Division
- Overflow
- Floating-point representation
- Computer arithmetic concepts
- Exam-oriented problems

### Chapter 4 — The Processor

- Processor datapath
- Control
- Instruction execution
- Single-cycle processor concepts
- Pipelining
- Pipeline hazards
- Data hazards
- Control hazards
- Performance considerations
- Processor-related numerical problems

### Chapter 5 — Large and Fast: Exploiting Memory Hierarchy

- Memory hierarchy
- Cache memory
- Locality
- Cache mapping
- Cache hits and misses
- Cache performance
- Main memory
- Virtual memory
- Memory hierarchy performance
- Exam-oriented numerical problems

## Features

- Chapter-based navigation
- Learn and Problems modes
- Short concept explanations
- Worked examples
- Real practice-sheet problems
- Model solutions
- True/False preparation
- Progress indicators
- Problem completion tracking
- Review-again workflow
- Clean dark interface
- Exam-focused organization
